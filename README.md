## 📌 Project Overview
This project was built as an environment art and composition study in Unreal Engine 5. It incorporates multiple high-quality asset packs to create an atmospheric jungle archipelago with dense foliage, realistic water, and rural island structures.

### Key Features:
- **Environment Design:** Tropical islet settlement with custom lighting and atmosphere.
- **Foliage & Nature:** Integrated high-density trees, foliage, and Megascans landscape materials with wind animation.
- **Cinematic Sequence:** Features an in-engine Level Sequence (`AncientSequence`).
